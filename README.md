# 将星之路 · 军事生涯模拟

一款纯前端的**虚构军事题材生涯模拟小游戏**：从入伍新兵起步，通过属性养成、任务抉择、带兵历练，一步步走上将星之路。

> ⚠️ 本作品为虚构题材。人物、部队番号、事件与战役均系虚构，不涉及任何现实人物、单位与事件。

## 在线试玩

- 网页版：<https://houhuizhang80-wq.github.io/jiangxing-zhilu/>
- 单文件版：仓库内 `将星之路-单文件版.html`，双击即可离线游玩

## 玩法概览

| 系统 | 说明 |
| --- | --- |
| 六维属性 | 体魄、智谋、统率、魅力、信念、意志，开局可自由分配 30 点 |
| 派生指标 | 军事素养、政治素养、专业能力，由属性与经历共同决定 |
| 动态状态 | 士气、健康、威望、首长信任、搭档默契、家庭 |
| 军衔阶梯 | 功勋门槛呈加速曲线，越高阶晋升越难 |
| 技能体系 | 4 大分支 × 5 个技能，等级 E → S |
| 性格特质 | 由抉择逐步塑造，影响判定与事件走向 |
| 抉择事件 | 覆盖早、中、后期，含二周目专属事件线 |
| 同期排名 | 与同期军官比较位次，决定资源与机会 |
| 成就 / 周目 | 成就跨周目累积；二周目继承父辈「家训」 |
| 结局系统 | 依据生涯轨迹结算多种结局 |

## 项目结构

```
index.html                入口页面
css/style.css             样式
js/data.js                数据层：军衔 / 属性 / 行动 / 技能 / 特质 / 事件 / 结局
js/engine.js              引擎层：回合推进、判定、晋升与结算
js/ui.js                  界面层：渲染、弹窗、任务小游戏
tools/build.js            打包单文件 HTML
tools/smoke.js            界面层冒烟测试（最小 DOM 桩跑完整一局）
tools/simulate.js         自动模拟器：批量随机生涯，检验晋升与卡关点
tools/debug.js            调试脚本：健康曲线 / 结束原因 / 行动消耗
将星之路-单文件版.html     构建产物（可离线单文件运行）
```

## 本地运行

纯静态站点，无需构建即可直接打开 `index.html`；若需本地服务器：

```bash
python -m http.server 8000
# 或
npx serve .
```

## 开发与测试

需要 Node.js：

```bash
node tools/build.js       # 重新生成单文件版
node tools/smoke.js       # 冒烟测试
node tools/simulate.js    # 生涯模拟统计
node tools/debug.js       # 数值调试
```

## 部署

仓库根目录即为站点根目录，已包含 `.nojekyll`，可直接由 GitHub Pages 托管（分支 `main`，路径 `/`）。
